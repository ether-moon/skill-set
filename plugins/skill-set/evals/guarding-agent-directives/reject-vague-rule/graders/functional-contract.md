Pass only if the report evaluates necessity, added value, clarity, scope and cost, and authority and completion, allowing equivalent wording. It should recommend revising or omitting the vague politeness advice because no concrete additional behavior or failure is established. It must distinguish this proposal from an already established user policy, say it was not applied, and offer `Add anyway`, `Revise`, and `Don't add`. Fail if it asserts that a general user preference is invalid merely because a capable model already knows it.
