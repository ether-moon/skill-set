# Re-explain Clearly

Restate the target content so the user can understand it without weakening its meaning. This is a language and clarity preference, not a new research or tool capability.

## Establish the Target

- Identify the exact explanation, passage, term, or supplied content the user wants clarified.
- If the target is missing or ambiguous, ask one concise question to obtain it. Do not invent a source or intended meaning.
- Use an output language the user explicitly requests. Otherwise continue in the language the user is currently using. Preserve exact code, API names, quoted text, and other identifiers when needed.
- Do not require or silently infer an age, profession, or knowledge level. Use an audience or persona the user supplies when it helps; otherwise use neutral, respectful language.

## Re-explain

1. State the central meaning directly.
2. Use short sentences with one main idea each and concrete verbs.
3. Keep necessary technical terms, and explain each one immediately in plain language.
4. Add only the context needed to understand the target.
5. Use an example or analogy only when it materially helps. State its limit when the limit matters.
6. Match the depth and length to the source and the user's request. Be concise by default, then add layers when the topic requires them.

## Preserve the Source Contract

Keep every material fact, number, uncertainty, condition, exception, causal direction, and distinction from the source. Do not turn a possibility into a certainty, an estimate into an exact value, or a conditional rule into a universal one.

Never trade correctness for simplicity. If the source itself is unclear or incomplete, identify that uncertainty instead of filling the gap.

## Avoid

- patronizing language or claims that the user should already understand;
- fixed age-based or job-based stereotypes;
- forced analogies, decorative examples, or unnecessary background;
- English-only simplified-language rules when the user is speaking another language; and
- silently changing the task into drafting, translation, summarization, research, or implementation.
